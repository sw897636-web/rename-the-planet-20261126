Entry for the make.fun bounty **Rename the Planet**: one funny new name for a
planet in our solar system, plus the why, in a single line under 200
characters.

`main.ts` (Node 22, standard library only) writes the entry deterministically
to `/output/entry.txt`:

> Renaming Neptune 'The Bouncer': 2,100 km/h winds, minus 200 degrees, and it still won't let anything in.

Run it with `node main.ts` (no dependencies needed beyond
Node itself; the file uses only `node:fs`). Running it twice produces
byte-identical output.
